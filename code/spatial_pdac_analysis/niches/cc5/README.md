# CC5 Contours

This folder contains the different CC5 contour views.

CC5 was one of the first niches we wanted to visualize directly because several KCN looked related to it.

Scripts:
- `run_cc5_contours_on_ecotype_maps.R`
- `run_cc5_contours_on_grey_spots.R`
- `run_cc5_contours_only.R`

Outputs:
- ecotype maps with CC5 contour
- grey spot maps with CC5 contour
- contour-only version

## Requirements
- `R 4.5.x`
- Main R packages:
  `Seurat`, `dplyr`, `tibble`, `ggplot2`, `sf`, `patchwork`
- Main input:
  `../../inputs/PDAC_Updated_ST.rds`
