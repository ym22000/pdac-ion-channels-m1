# Marker Projections

This folder contains simple spatial projections for a few reference markers.

These marker maps help anchor the KCN results against basic stromal and epithelial signals.

Main script:
- `run_marker_projections.R`

Markers currently used:
- `COL1A1`
- `FAP`
- `EPCAM`
- `KRT20`
- `C7`
- `C1R`
- `CCL19`
- `CCL21`
- `MFAP4`
- `CLU`
- `DCN`
- `CCN2`
- `ACTA2`
- `THBS1`
- `COL12A1`

These plots help compare KCN territories with basic stromal and epithelial signals.

## Requirements
- `R 4.5.x`
- Main R packages:
  `Seurat`, `dplyr`, `tibble`, `ggplot2`
- Main input:
  `../../inputs/PDAC_Updated_ST.rds`
