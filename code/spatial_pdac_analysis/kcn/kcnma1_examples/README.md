# KCNMA1 Example Plots

This folder contains a few KCNMA1-specific plots.

These plots were useful to inspect KCNMA1 alone because it quickly emerged as one of the most interesting KCN spatially.

Scripts:
- `run_kcnma1_spatial_expression_maps.R`
- `run_kcnma1_expression_on_ecotype_maps.R`

These files give a compact KCNMA1-only view of the same spatial dataset.

## Requirements
- `R 4.5.x`
- Main R packages:
  `Seurat`, `dplyr`, `tibble`, `ggplot2`
- Main input:
  `../../inputs/PDAC_Updated_ST.rds`
