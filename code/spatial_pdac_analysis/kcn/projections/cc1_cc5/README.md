# KCN Maps with Combined CC1 and CC5 Contours

This folder contains the KCN expression maps with the merged CC1+CC5 contour.

It helps compare each KCN with the broader CC1+CC5 territory instead of with a single ecotype only.

Main script:
- `run_kcn_expression_maps_with_cc1_cc5_contours.R`

## Requirements
- `R 4.5.x`
- Main R packages:
  `Seurat`, `dplyr`, `tibble`, `ggplot2`, `sf`, `RColorBrewer`
- Main input:
  `../../../inputs/PDAC_Updated_ST.rds`
