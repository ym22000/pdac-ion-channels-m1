# KCN Maps with Combined CC2 and CC3 Contours

This folder contains the KCN expression maps with the merged CC2+CC3 contour.

It helps compare each KCN with the broader CC2+CC3 tumor-associated territory.

Main script:
- `run_kcn_expression_maps_with_cc2_cc3_contours.R`

## Requirements
- `R 4.5.x`
- Main R packages:
  `Seurat`, `dplyr`, `tibble`, `ggplot2`, `sf`, `RColorBrewer`
- Main input:
  `../../../inputs/PDAC_Updated_ST.rds`
