# KCN Maps with CC5 Contours

This folder contains the KCN expression maps with the CC5 contour.

It helps check whether a given KCN visually overlaps with the CC5 territory.

Main script:
- `run_kcn_expression_maps_with_cc5_contours.R`

## Requirements
- `R 4.5.x`
- Main R packages:
  `Seurat`, `dplyr`, `tibble`, `ggplot2`, `sf`, `RColorBrewer`
- Main input:
  `../../../inputs/PDAC_Updated_ST.rds`
