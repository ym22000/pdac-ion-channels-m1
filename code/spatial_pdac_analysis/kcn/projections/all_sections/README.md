# Base KCN Maps

This folder contains the base KCN expression maps.

This is the cleanest starting point to look at each KCN before adding niche contours or other overlays.

Main script:
- `run_kcn_expression_maps.R`

Output:
- one PDF per KCN on the selected normal and primary sections

## Requirements
- `R 4.5.x`
- Main R packages:
  `Seurat`, `dplyr`, `tibble`, `ggplot2`
- Main input:
  `../../../inputs/PDAC_Updated_ST.rds`
